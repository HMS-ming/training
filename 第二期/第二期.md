# 🌟 第二期培训 · STM32 与机械设计实战手册

> 📖 *面向通过第一期面试、进入正式阶段的成员：从"看得懂"走到"做得出"。*
> 🗓️ *周期：2026.11.07 — 2026.12.06（共 4 周 + 结营 2 天）*
> 🎯 *主线：STM32（电控）｜辅线：机械设计（STEP 提交）｜出口：个人独立完成的作品 + 完整作品说明 + 演示视频*

---

## 一、本期定位

第一期解决"入门"：C/C++、Git、大模型，让人**能写、能存、能问**。
第二期解决"上手"：把代码落到硬件上，把想法落到结构上，让人**能做出来**。

本期不再铺开三个方向，集中两件事：

- **STM32 基础（主线，占约 3 周）**：用 **STM32CubeMX + VS Code、HAL 库**，以 **Keysking 的 STM32 教程**为教材，打通「建工程 → 点灯 → 串口 → 中断/定时器 → PWM/ADC → 最终考核作品」。
- **机械设计（辅线，集中 5 天）**：跟 **Fusion 360 2023 版教程**，完成第 26 课「萝卜塔」、第 42 课「汤勺」两个作业；其余课时按需选学。

两条线都由**个人独立完成**，不分组、不组队：**STM32 负责"动"，机械设计负责"装"**，每人最终交出一个自己做的作品。

> 💡 机械教程以 **Fusion 360** 为主，但**软件不限定**：会用 SolidWorks / Rhino（犀牛）的同学可以用自己的软件完成作业，**统一交 STEP 通用格式**。

## 四、组织与分工

- **个人独立完成**：本期全部作业与最终作品均为个人项目，**不分组、不组队**；允许讨论，但不允许共用代码或代做。
- **主讲**：STM32 主讲 1 名、机械主讲 1 名、助教 1~2 名，由运营组在开营前确定。
- **设备**：STM32 开发板、ST-Link、传感器、舵机按个人借用，**借用登记、损坏报备**；3D 打印机按个人预约使用。
- **答疑顺序**：① 查 Keysking 对应集 / Fusion 教程对应课 → ② 问 AI → ③ 问助教 → ④ 问主讲。
- **作业提交**：按 [第二期作业提交说明](提交格式说明.md) 摆文件、发链接；每周由助教逐人验收。

## 五、考核与验收（对齐运营方案）

| 维度 | 权重 | 量化标准 |
|------|------|----------|
| **周任务完成度** | 40% | 每周验收按期完成率 ≥ 80%；每章练习与机械两作业至少完成必做项 |
| **最终考核作品** | 40% | 作品说明完整、演示视频可播放、现场功能演示正常；缺一项扣分 |
| **工程规范** | 10% | Git 提交清楚、目录规范、关键代码有注释、有 debug 笔记 |
| **答辩表现** | 10% | 3 分钟讲清「做了什么、怎么做的、卡在哪、怎么解决」 |

**流动管理**（沿用《追光空间站运营方案》）：

- 单次不达标 → 预警一次，由主讲/助教跟进原因；
- 连续 2 周任一指标不达标，或无故失联超 1 周 → 按运营方案预警/淘汰流出；
- 各项考核维度全达标且答辩 ≥ 85 分 → 记优秀一次，作为内推评定依据之一。

## 六、结营考核作业（个人独立完成）

本期不设分组项目，每人独立完成以下两部分。

### A · STM32 最终考核作品

- **硬件范围固定，选题自由发挥**：主控必须使用 **STM32F103C8T6** 最小系统板；做一个小作品，题目自定（传感器、显示、控制、小游戏等均可）。
- **允许参考与复刻**：可以参考各种开源方案、可以复刻现成作品，但**代码、接线、结构、调试必须个人自制**；在作品说明中注明参考来源。
- **必交两样**：
  1. **完整作品说明**：功能、硬件清单、接线表、实现思路、参考来源、遇到的问题与解决、测试结果（模板见[提交说明](提交格式说明.md)）。
  2. **演示视频**：上传至 GitHub（大文件走 Release 附件，不要直接 commit）。
- **不交工程源码**：最终考核只看作品说明、演示视频与现场演示，不需要提交完整工程源码。
- **现场演示**：结营当天上电演示，能讲清功能与实现思路。

### B · 机械设计作业（3D 设计，交 STEP）

- **必做**：教程第 **26 课「萝卜塔」**、第 **42 课「汤勺」**。
- **必交**：两个作业的 **STEP 通用格式**（`.step` / `.stp`）+ 关键步骤截图 + 完成效果图（渲染或截图）；原生源文件（`.f3d` / `.sldprt` / `.3dm` 等）可选，建议一并提供。
- **要求**：按教程跟做；允许按比例/尺寸微调，但要在说明里写清改了什么、为什么。

**统一交付**：按 [第二期作业提交说明](提交格式说明.md) 摆进个人仓库；结营当天现场演示 STM32 作品 + 展示机械作业。

## 八、安全与纪律

- **用电**：接线前先断电；电源正负极不短接；舵机/电机独立供电并与开发板**共地**。
- **烧录**：确认芯片型号与板子供电电压，避免 5V 直灌 3.3V 引脚。
- **3D 打印**：不触碰热端与热床；打印期间有人在场；取件等冷却。
- **设备**：借用登记，损坏第一时间报备，不私自拆装。
- **诚信**：代码与模型自己动手；参考教程/他人代码需注明来源，不直接提交他人成果。

## 九、常见问题

**Q1：没有开发板怎么办？**
按个人借用团队设备；如需自购，优先 STM32F103C8T6 最小系统板 + ST-Link，成本低、资料多。

**Q2：一期 C 语言没学扎实，能跟上吗？**
能。STM32 入门主要用 C 的基本语法与结构体，指针理解不深也能先跑通；遇到卡点按「查教程 → 问 AI → 问助教」补。

**Q3：VS Code 编译/烧录报错怎么办？**
先看报错第一行（CubeMX 芯片包没装、VS Code 构建任务/编译器路径没配好、ST-Link 驱动未装、调试配置不对），把整段报错贴给 AI 或群里，附上芯片型号与接线照片。

**Q4：Fusion 360 收费吗？不用它行不行？**
个人/学生可申请免费授权；不想用 Fusion 也可以用 SolidWorks / Rhino（犀牛）等，**作业统一交 STEP**。

**Q5：12 月考试周冲突怎么办？**
提前 24 小时在群里报备，第 4 周任务可降载或延至结营前补交；不报备按缺勤处理。

**Q6：机械线只有 5 天，够吗？**
够完成教程第 26 课「萝卜塔」和第 42 课「汤勺」两个作业；中间课时按需选学，想深入（曲面、渲染、仿真）放到项目里继续。
