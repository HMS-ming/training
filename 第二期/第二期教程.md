## 二、主线 A · STM32（第 1~6 章，全员必修）

> **教材**：[Keysking 的 STM32 教程](https://www.bilibili.com/video/BV12v4y1y7uV)（B 站完结合集）
> **工具**：STM32CubeMX + VS Code（HAL 库）+ ST-Link
> **总时长**：11.07 — 11.29（约 3 周）

| # | 章节 | 时间 | 核心内容 | 对应 Keysking 主题 |
|---|------|------|----------|--------------------|
| 1 | 开发环境与第一个工程 | 11.07 — 11.09 | CubeMX + VS Code 安装、新建 HAL 工程、时钟配置、编译烧录、工程目录 | 第 0 集起：环境安装、点灯、工程结构 |
| 2 | GPIO 与时钟树 | 11.10 — 11.13 | 时钟树、GPIO 输出/输入、LED、按键、上下拉 | GPIO、时钟树、按键输入 |
| 3 | 串口与调试 | 11.14 — 11.16 | UART 配置、`printf` 重定向、轮询/中断接收、波特率 | 串口轮询、串口中断 |
| 4 | 中断与定时器 | 11.17 — 11.20 | NVIC、外部中断 EXTI、定时器基本定时、中断回调 | 中断、基本定时器 |
| 5 | PWM 与 ADC | 11.21 — 11.24 | PWM 输出、呼吸灯、舵机角度、ADC 单通道/多通道 | PWM、ADC、舵机 |
| 6 | 最终考核作品 | 11.25 — 11.29 | 固定 STM32F103C8T6，自由选题；可参考/复刻开源方案，个人自制 | 综合应用（自拟） |

### 各章目标与练习

#### 第 1 章 · 开发环境与第一个工程（11.07 — 11.09）

**目标**：不依赖别人的工程，自己从零建一个能烧录的工程。

**核心步骤**
1. 安装 STM32CubeMX、VS Code，按 Keysking 教程装好 STM32 开发相关插件与工具链。
2. CubeMX 选芯片 → 配置调试接口（SWD）→ 配置时钟 → 生成 **HAL 库**工程（按 Keysking 教程选 Makefile / CMake 工程）。
3. 在 VS Code 里按 Keysking 教程配置编译与下载任务（ST-Link），编译并烧录。
4. 记录：芯片型号、时钟频率、下载器设置、工程目录结构。

**练习/验收**
- [ ] 自己新建的工程能编译通过、0 error
- [ ] 成功烧录，板子有反应（先烧一个点灯或空循环）
- [ ] 写清一页「工程配置笔记」（芯片、时钟、烧录设置）

> ⚠️ 常见坑：CubeMX 芯片包没装找不到芯片、VS Code 构建任务/编译器路径没配好、ST-Link 驱动未装、SWD 接线反了。

#### 第 2 章 · GPIO 与时钟树（11.10 — 11.13）

**目标**：理解"时钟是单片机的脉搏"，能读写引脚。

**核心内容**
- 时钟树：HSE/HSI → PLL → SYSCLK → AHB/APB 分频；为什么外设要先开时钟。
- GPIO 八种模式：推挽/开漏、上拉/下拉、复用、模拟；输入与输出的区别。
- `HAL_GPIO_WritePin` / `TogglePin` / `ReadPin` 的用法。

**练习/验收**
- [ ] LED 闪烁（500 ms 翻转）
- [ ] 按键控制 LED 亮灭（含消抖）
- [ ] 按键长按/短按区分（选做）
- [ ] 用 CubeMX 截图标注你配置的引脚与时钟

#### 第 3 章 · 串口与调试（11.14 — 11.16）

**目标**：让板子"说话"，这是后面所有调试的基础。

**核心内容**
- UART 参数：波特率、数据位、停止位、校验位；TX/RX 交叉接线。
- `printf` 重定向到 UART（按 Keysking 教程的 `_write` / `fputc` 方式）。
- 轮询发送 / 中断接收；接收不定长数据的思路。

**练习/验收**
- [ ] 串口助手收到 `Hello LightChaser`
- [ ] 用 `printf` 打印变量（如循环计数）
- [ ] 电脑发字符，板子收到后回显
- [ ] 把波特率改错一次，观察乱码并改回（理解波特率）

#### 第 4 章 · 中断与定时器（11.17 — 11.20）

**目标**：从"轮询"升级到"事件驱动"，让程序不再死等。

**核心内容**
- NVIC 优先级、抢占与子优先级；中断服务函数与回调。
- EXTI 外部中断：按键触发、消抖。
- 定时器：预分频 PSC、自动重装 ARR、计数模式；1 ms / 1 s 定时。
- 中断里"只置标志、主循环干活"的原则。

**练习/验收**
- [ ] 按键用 EXTI 中断控制 LED（不轮询）
- [ ] 定时器 1 s 中断翻转 LED
- [ ] 用定时器中断做软件计时，串口每秒打印一次
- [ ] 说明你的中断优先级配置

#### 第 5 章 · PWM 与 ADC（11.21 — 11.24）

**目标**：会输出"可调的电压/占空比"，会读"模拟世界的数值"。

**核心内容**
- PWM：频率与占空比、`HAL_TIM_PWM_Start`、`__HAL_TIM_SET_COMPARE`。
- 舵机：50 Hz、0.5~2.5 ms 脉宽对应 0~180°；独立供电、共地。
- ADC：分辨率、参考电压、单次/连续转换、轮询/中断/DMA（入门先轮询）。
- 传感器：电位器、光敏、红外中的至少一种。

**练习/验收**
- [ ] PWM 呼吸灯（占空比渐变）
- [ ] 串口输入角度，舵机转到对应角度
- [ ] ADC 读取电位器/光敏，串口打印电压或原始值
- [ ] 记录舵机供电方式与共地接法

#### 第 6 章 · 最终考核作品（11.25 — 11.29）

**目标**：用 **STM32F103C8T6** 独立完成一个小作品，并形成「作品说明 + 演示视频」两件套。

**选题（自由发挥）**：主控固定为 **STM32F103C8T6**，做一个小作品，题目自定；**可以参考各种开源方案、可以复刻**，但代码、接线、结构、调试必须个人自制，并在作品说明中注明参考来源。

**必交**
- **完整作品说明**：功能、硬件清单、接线表、实现思路、参考来源、问题与解决、测试结果（模板见[作业提交说明](提交格式说明.md)）。
- **演示视频**：上传至 GitHub（大文件走 Release 附件，不要直接 commit）。

**不交工程源码**：最终考核只看作品说明与演示视频，不需要提交完整工程源码。

**硬件范围**：主控固定为 STM32F103C8T6；传感器、显示、执行器等模块**自行购买**，团队不提供借用。

**验收**
- [ ] 演示视频中作品能正常工作，不依赖临时改代码
- [ ] 作品说明按模板写完整，并注明参考来源
- [ ] 演示视频已上传 GitHub，链接可访问

## 三、辅线 B · 机械设计（Fusion 360 2023 教程）

> **教材**：[2023 年最新 Fusion 360 教程（持续更新中）](https://www.bilibili.com/video/BV1xX4y1E7nG?vd_source=ea26a129679379213be9799d9c771166)
> **必做作业**：第 **26 课 萝卜塔**、第 **42 课 汤勺**
> **软件**：教程以 **Fusion 360** 为主；已会 SolidWorks / Rhino（犀牛）的同学可用自己的软件完成作业，**统一交 STEP 通用格式**；用其他软件时，把教程命令对应到同类命令即可
> **工具**：Fusion 360（学生/个人免费授权，非强制）
> **总时长**：11.30 — 12.04（集中 5 天，其余课时按需选学）

| # | 单元 | 时间 | 核心内容 |
|---|------|------|----------|
| 1 | 界面与草图 | 11.30 | 工作空间、基准面、草图约束（全约束）、尺寸标注、拉伸入门 |
| 2 | 常用特征 | 12.01 | 旋转、切除、孔、圆角、倒角、阵列、抽壳 |
| 3 | 作业一 · 第 26 课 萝卜塔 | 12.02 | 跟做萝卜塔，记录命令与尺寸；交 STEP + 过程截图 |
| 4 | 曲面与进阶 | 12.03 | 曲面、放样、扫掠等（按教程对应课时选学，为汤勺铺垫） |
| 5 | 作业二 · 第 42 课 汤勺 | 12.04 | 跟做汤勺，完成曲面过渡与收尾；交 STEP + 效果图 |

### 各单元目标与练习

#### 单元 1 · 界面与草图（11.30）

- 认识 Fusion 360 的「草图 → 实体 → 修改 → 导出」工作流。
- 草图**全约束**：几何约束（水平/垂直/相切/同心）+ 尺寸约束。
- **练习**：画一个带 4 个安装孔的矩形底板草图，做到完全约束。

#### 单元 2 · 常用特征（12.01）

- 高频命令：拉伸、旋转、切除、孔、圆角、倒角、阵列、抽壳。
- **练习**：用上述命令做 2~3 个简单零件，熟悉参数面板。

#### 单元 3 · 作业一：第 26 课 萝卜塔（12.02）

- 按教程第 26 课完整跟做「萝卜塔」。
- **记录**：用了哪些命令、关键尺寸怎么定、和教程有哪些偏差。
- **交付**：**STEP 通用格式**（`.step` / `.stp`）+ 3~5 张关键步骤截图 + `说明.md`；原生源文件（`.f3d` / `.sldprt` / `.3dm`）可选。

#### 单元 4 · 曲面与进阶（12.03）

- 按教程对应课时学习曲面、放样、扫掠等工具，为「汤勺」做准备。
- **练习**：做一个简单的曲面过渡件，能说明曲面与实体的区别。

#### 单元 5 · 作业二：第 42 课 汤勺（12.04）

- 按教程第 42 课完整跟做「汤勺」。
- **交付**：**STEP 通用格式**（`.step` / `.stp`）+ 完成效果图（渲染或截图）+ `说明.md`；原生源文件可选。
- **选做**：需要打印时在 Q 群提出，后期按需求提供部分 3D 打印服务；打印后附实物照片与打印参数。
