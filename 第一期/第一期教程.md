## ✅ 验收清单

### 🔴 核心（第 1~3 章）—— 必学，需交付，这是本次培训的重点

- [ ] **C/C++**：第 1 章练习全部跑通（Hello World、计算器、奇数和、指针交换、malloc 求平均）
- [ ] **C/C++**：把这些练习入库，提交到你的 GitHub 仓库
- [ ] **大模型**：能用网页版 DeepSeek 让 AI 解释指针代码
- [ ] **大模型**：能在 Trae / VS Code 里选中代码让 AI 解释 / 找 bug
- [ ] **大模型**：成功运行 `llm_test.py`，用代码调通一次 DeepSeek
- [ ] **Git**：自己的 GitHub 仓库有多次提交记录（展示你能 clone → 改 → push）
- [ ] 把核心成果仓库链接发给学长 / 放进团队仓库（即交付完成）

### 🟢 进阶方向（第 6~11 章）—— 选学，挑**一个方向**深入

选一个方向把它做扎实，别贪多：

- [ ] **电控**：LED 亮 / 串口打印，或跑通 ROS 小乌龟 → 附烧录视频或截图
- [ ] **算法**：用 OpenCV 处理过一张图，或跑通一个大模型分类例子 → 附输入输出图/结果
- [ ] **机械**：完成一个 3D 零件建模 / 打印实物 / 画一张三视图 → 附模型与截图
- [ ] 每个踩过的坑记进你自己的 `学习笔记.md`

> 核心之外，学有余力再拓宽。**先跑通，再问为什么**——能把前三章吃透并交付、选一个方向做扎实，你已经很不错了。
