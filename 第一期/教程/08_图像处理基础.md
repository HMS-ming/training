## 8.1 图像在电脑里是什么

一张图 = 一个**像素矩阵**：
- **灰度图**：每像素 1 个数（0~255，黑→白）。
- **彩色图**：每像素 3 个数（R/G/B）。
- 所以图像处理 = **对矩阵做运算**，这就是它和"算法"沾边的根本原因。

## 8.4 最基本的三种处理（照做）

```python
import cv2

img = cv2.imread("你的图片.jpg")

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)   # 1. 转灰度
small = cv2.resize(img, (0, 0), fx=0.5, fy=0.5)  # 2. 缩小一半
blur = cv2.GaussianBlur(img, (9, 9), 0)         # 3. 高斯模糊（去噪）
edges = cv2.Canny(gray, 50, 150)                # 4. Canny 边缘检测
```
`edges` 会得到一张"画出了所有物体轮廓"的图——机器人识别物体的第一步常常就是先找边缘。

## 8.5 处理视频 / 摄像头（机器人视觉的真身）

机器人看到的不是一张图，而是一**连串**画面。读取摄像头很简单：

```python
import cv2

cap = cv2.VideoCapture(0)          # 0 = 你的摄像头
while True:
    ret, frame = cap.read()        # 读一帧
    if not ret:
        break
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)   # 每帧都转灰度
    cv2.imshow("feed", gray)
    if cv2.waitKey(1) & 0xFF == ord("q"):   # 按 q 退出
        break
cap.release()
cv2.destroyAllWindows()
```

> 记住"**一帧就是一张图**"，你在图片上写的所有处理，套进 `while` 循环就变成"实时视觉"。机器人寻迹、避障都是这么做的。

## 8.6 颜色识别：挑出"红色"（识别目标的基础）

很多机器人靠颜色找目标（红球、蓝色胶带）。做法是转 **HSV** 色彩空间再加阈值：

```python
import cv2
import numpy as np

img = cv2.imread("你的图片.jpg")
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

# 红色的 HSV 范围（调这两个范围就能识别其他颜色）
lower = np.array([0, 100, 100])
upper = np.array([10, 255, 255])
mask = cv2.inRange(hsv, lower, upper)   # 得到"哪里是红色"的掩膜

# 在原图上看效果
res = cv2.bitwise_and(img, img, mask=mask)
```

- **HSV 是什么**：把颜色拆成"色相 H / 饱和度 S / 明度 V"，比 RGB 更容易按"颜色"取范围。
- 调范围有多烦？把范围提问丢给 DeepSeek，让它教你一步步调。
- 颜色识别 → 后面接上"找轮廓、算中心点"，机器人就能"锁定目标"了。

## 8.7 小项目：找到画面里最大的物体（走向视觉定位）

```python
import cv2
import numpy as np

img = cv2.imread("你的图片.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, thresh = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)   # 二值化
contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

# 找面积最大的轮廓，画出来
c = max(contours, key=cv2.contourArea)
x, y, w, h = cv2.boundingRect(c)
cv2.rectangle(img, (x, y), (x + w, y + h), (0, 255, 0), 2)   # 画个框住它
cv2.imshow("result", img); cv2.waitKey(0)
```

做完这个，你就碰触到了**"目标检测"的雏形**——第 9 章学机器学习后再叠加分类，就是完整的目标识别了。
