## 8.1 图像在电脑里是什么

一张图 = 一个**像素矩阵**：
- **灰度图**：每像素 1 个数（0~255，黑→白）。
- **彩色图**：每像素 3 个数（R/G/B）。
- 所以图像处理 = **对矩阵做运算**，这就是它和"算法"沾边的根本原因。

## 8.3 读入、显示、保存

```python
import cv2

img = cv2.imread("你的图片.jpg")   # BGR 三通道
# 有窗口就用 cv2.imshow，否则用 matplotlib 显示更省事
import matplotlib.pyplot as plt
plt.imshow(cv2.cvtColor(img, cv2.COLOR_BGR2RGB))
plt.axis("off"); plt.show()
```

## 8.4 最基本的三种处理（照做）

```python
import cv2

img = cv2.imread("你的图片.jpg")

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)   # 1. 转灰度
small = cv2.resize(img, (0, 0), fx=0.5, fy=0.5)  # 2. 缩小一半
blur = cv2.GaussianBlur(img, (9, 9), 0)         # 3. 高斯模糊（去噪）
edges = cv2.Canny(gray, 50, 150)                # 4. Canny 边缘检测
```
`edges` 会得到一张"画出了所有物体轮廓"的图——机器人识别物体的第一步常常就是先找边缘。
