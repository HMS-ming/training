# 4. 🟢 Linux 基础 🐧
**🌐 方向：公共基础（各方向都会用到）**

> ✨ [← 返回教程索引](../第一期教程.md)

**目标：** 认识 Linux，会常用的命令行，为嵌入式 / ROS 做准备。
**定位：** 对大一新生，先"认识会用"，不要求一次学完。

---

1. 准备一个 Ubuntu 环境（虚拟机 / 双系统 / 云主机任选其一）。
2. 打开终端，逐个敲并观察结果：
   ```bash
   pwd            # 我在哪
   cd /home       # 去/home目录
   ls             # 这里有什么
   mkdir test     # 新建文件夹 test
   sudo apt update    # 更新软件源（看它输出了什么）
   ```
3. 装一下 C 编译器（和第 1 章呼应）：`sudo apt install -y gcc build-essential`
4. 了解：文件目录结构、权限、文件读写。不用背，先"见过、会用常用那几个"。

> 🎬 **配套视频**：跟着 [韩顺平 · Linux 从零入门](https://www.bilibili.com/video/BV1Sv411r7vd/)（494万播放 · 153集）把常用命令过一遍，不熟的回看划线。

> 对新生：Linux 一开始会不习惯，别慌，先每天用 10 分钟练几个命令，慢慢就熟了。
