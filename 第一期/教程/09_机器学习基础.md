## 9.1 机器学习是"教"不是"写"

写普通程序是**你告诉电脑每一步怎么做**；机器学习是**你给电脑一堆数据和答案，让电脑自己找出规律**（这叫"训练"），再用这规律预测新数据（这叫"推理"）。

两个概念先记住：
- **监督学习**：给的数据自带正确答案（"这张是猫"），学"输入→答案"的映射。
- **无监督学习**：只有数据没有答案，让程序自己聚类分组。
- **特征**：用来判断的数据（比如花的萼片长、颜色）。

## 9.2 跑通第一个例子：鸢尾花分类

用最经典的 sklearn 示例，照抄就能跑：

```bash
pip install scikit-learn matplotlib
```

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)          # X=特征, y=花的种类
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

model = RandomForestClassifier()
model.fit(X_train, y_train)                # 训练：让模型从数据里学
pred = model.predict(X_test)               # 推理：对没见过的数据预测
print("准确率:", accuracy_score(y_test, pred))  # 应该在 0.9 以上
```
看到 90%+ 的准确率了吗？——你已经"训练出一个模型让它给新品种鸢尾花分类"了。
