## 9.1 机器学习是"教"不是"写"

写普通程序是**你告诉电脑每一步怎么做**；机器学习是**你给电脑一堆数据和答案，让电脑自己找出规律**（这叫"训练"），再用这规律预测新数据（这叫"推理"）。

两个概念先记住：
- **监督学习**：给的数据自带正确答案（"这张是猫"），学"输入→答案"的映射。
- **无监督学习**：只有数据没有答案，让程序自己聚类分组。
- **特征**：用来判断的数据（比如花的萼片长、颜色）。

## 9.2 跑通第一个例子：鸢尾花分类

用最经典的 sklearn 示例，照抄就能跑：

```bash
pip install scikit-learn matplotlib
```

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)          # X=特征, y=花的种类
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

model = RandomForestClassifier()
model.fit(X_train, y_train)                # 训练：让模型从数据里学
pred = model.predict(X_test)               # 推理：对没见过的数据预测
print("准确率:", accuracy_score(y_test, pred))  # 应该在 0.9 以上
```
看到 90%+ 的准确率了吗？——你已经"训练出一个模型让它给新品种鸢尾花分类"了。

## 9.4 三个必须懂的概念：训练 / 测试 / 过拟合

你可能发现 9.2 里我们把数据拆成了 `X_train`（训练）和 `X_test`（测试），为啥？

- **训练集**：给模型"考试前做练习"的数据。
- **测试集**：模型从没见过的题，用来**检验它真会还是死记硬背**。
- **过拟合（overfitting）**：模型把练习答案背得太熟，一到新题就蒙。表现就是"训练准确率很高、测试准确率低"。**数据多、模型简单一点**能缓解。

```python
# 你可以在 9.2 里加一行感受一下：
train_acc = model.score(X_train, y_train)
test_acc  = model.score(X_test,  y_test)
print(f"训练 {train_acc:.2f} | 测试 {test_acc:.2f}")   # 两者差距太大 = 可能过拟合
```

> 记住投资学的一句话：**别只信"训练得多好"，要看"没见过的问题答得怎么样"**——这就是测试集存在的意义。

## 9.5 除了分类，还有"回归"（预测一个数）

分类是"它属于哪类"，回归是**"它大概是多少"**（房价、温度、股票）。很接近：

```python
from sklearn.datasets import fetch_california_housing  # 房价数据集
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error

X, y = fetch_california_housing(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

model = RandomForestRegressor()
model.fit(X_train, y_train)                     # 训练
pred = model.predict(X_test)                    # 预测房价
print("均方误差 MSE:", round(mean_squared_error(y_test, pred), 3))   # 越小越准
```

跑通它，你就有"分类 + 回归"两大能力了——机器学习最常用的就这两类。

## 9.6 把模型"存下来"，下次直接用（工程习惯）

训练一次可能很慢，别每次都重训。学会保存模型：

```python
import joblib
joblib.dump(model, "my_model.pkl")        # 存盘
model2 = joblib.load("my_model.pkl")      # 下次直接加载
pred2  = model2.predict(X_test)           # 直接用，不用再训练
```

> 写完这个你就算入门了"训练好的模型拿去用"的工程套路——机器人里加载一个模型去识别目标的流程，跟这一模一样。
