# 6. 🟢 嵌入式基础 ⚙️
**🧭 方向：电控（嵌入式 / 硬件）**

> ✨ [← 返回教程索引](../第一期教程.md)

**目标：** 认识单片机，会用 **Keil + CubeMX（或 STM32CubeIDE）** 从零点亮一块板子上的 LED，并扩展点到定时器 / PWM / 串口。
**前置：** 第 1 章 C 语言（指针那节很重要）＋ 第 4 章 Linux（了解命令行即可）。
**预计：** 2~3 周。
**需要硬件：** 一块 STM32 开发板（如 STM32F103 Blue Pill / STM32F407）＋ ST-Link/串口下载线 ＋ 杜邦线（团队一般有）。

---

## 6.1 先搞懂：什么是单片机

单片机 = **一颗能独立跑程序的微型计算机**，上面有 CPU、内存、GPIO（可读写的引脚）、定时器等，用来控制 LED、电机、传感器。ROS 机器人里，单片机负责"动起来"的部分。

- **GPIO**：引脚（Pin）。可以**输出**高低电平（点亮 LED）、**输入**检测信号（按键、传感器）。
- **固件**：烧进芯片里的程序，写在 `main` 里，上电就跑。

## 6.2 搭建环境（选一条路）

- 路线 A（团队常用）：**CubeMX**（图形化生成初始化代码）＋ **Keil MDK**（写代码编译烧录）。
- 路线 B：**STM32CubeIDE**（一体化，CubeMX + 编译器 + 烧录），一条龙，建议新手用。
- 安装时选好你芯片型号的支持包（Pack）。

## 6.3 点亮第一颗 LED（核心步骤）

1. 在 CubeMX 里**新建工程**，选你的芯片型号。
2. 在引脚视图里，把一个引脚配置成 **GPIO_Output**，并设置初始电平。
3. 配置一个**系统时钟**（忽略细节，默认即可），然后 **Generate Code** 生成工程。
4. 打开生成的代码，在 `while(1)` 里写点灯逻辑：
   ```c
   // 让 LED 电平持续翻转：亮 → 灭 → 亮
   while (1)
   {
       HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);  // 翻转电平
       HAL_Delay(500);                              // 停 500ms
   }
   ```
5. **编译** → 连接下载器 → **烧录**到板子。
6. → 好了，LED 一愣一晃地亮起来，你的第一步嵌入式成功。

> 💡 若 LED 不亮，先查：引脚名对不对、是否烧录成功、板子供电、有没有接反/接错引脚。

## 6.4 让它更进一步（选做，强烈建议）

- **按键输入**：把一个引脚配成 Input，按下去读电平 → 点灯。
- **定时器 + PWM**：用定时器输出 PWM（脉宽调制），让 LED 由暗到亮渐变，或驱动舵机。舵机是机器人关节的基础。
- **串口（UART）打印**：用串口往电脑打印日志，这是嵌入式**调试**的命根子——学会打印 `printf` 之后，几乎所有问题都能定位。
- **中断**：按键用外部中断触发（不轮询）。
