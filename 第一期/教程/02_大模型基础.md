## 2.1 网页版：先把 DeepSeek 用起来

我们**主推 DeepSeek**，理由是它：
- 国内可直接访问、注册免费，日常学习用免费额度足够
- 中文理解好、**代码能力强**（有很多同学拿它应付刷题和课程作业）
- 还有推理模型 `deepseek-r1`，适合复杂逻辑题

1. 打开 [DeepSeek](https://chat.deepseek.com/) 注册登录。
   （备选：通义千问、Kimi、智谱清言、豆包；国外用 ChatGPT。）
2. 从具体提问开始，别问"怎么学 C 语言"这种空泛的，要这样问：
   - ✅ "我大一刚学 C，帮我用一句话说清 `int *p;` 是什么意思"
   - ✅ "这段代码报错 `segmentation fault`，帮我找原因：`<贴上你的代码>`"
   - ❌ "帮我写作业"（没意义，也学不到东西）
3. **把问题问清楚**：背景 + 目标 + 期望输出，比丢一句话好用得多。
4. 拿到的答案**自己亲手跑一遍**，看懂再改，别直接复制就交。

> 🔍 试着让 DS 帮你在第 1 章 [指针和内存](01_C语言基础.md) 的代码加注释——这也算第一个"AI 作业"。

## 2.2 在编辑器里边写边用 AI（效率翻倍的关键）

> 为什么非要这个？写代码时来回切网页很打断思路。把 AI **放进编辑器里**，选中一段代码就能问、就能改，学习速度快很多。

在编辑器里用 AI，有三种做法，**按从省事到自由排序**：

### 方式 A：用 Trae（AI 原生 IDE，最省事，推荐新手）

[Trae](https://www.trae.ai/) 是专门为 AI 打造的编辑器——**把 AI 助手直接内建**，不用自己配置模型深浅参数，开箱即用。

1. 下载并安装 Trae，用账号登录。
2. 在设置里找到**模型设置**，选择或添加 **DeepSeek**（按界面提示填入，通常会用 DeepSeek 的 API Key，见 2.3）。
3. 上手三个最常用的用法：
   - **选中代码 → 让 AI 解释 / 找 bug / 优化**：鼠标选中一段代码，旁边就弹 AI 面板，直接提问。
   - **@ 引用当前文件**：在对话里敲 `@` 加上文件名或选中代码块，AI 就能精确看到你的代码来回答。
   - **描述需求 → AI 直接改文件**：在对话里用大白话说"把这里的循环改成指针遍历"，AI 会帮你改；改完你逐个点确认。
4. 建议：让 AI 先当"解释器"（解释代码），再当"教练"（引导你自己写），最后才当"代笔"（帮你写）。

### 方式 B：用 VS Code + AI 插件（接 DeepSeek API）

如果你已经在用 VS Code，可以装 AI 编程插件把 DeepSeek 接进来（Continue / Cline / Roo Code 等任选一个）：

1. 在 VS Code 扩展商店搜并安装 **Continue**（或 Cline）。
2. 在插件的设置里，新建一个用 DeepSeek 的模型配置：
   - `模型`：`deepseek-chat`
   - `接口地址（base_url）`：`https://api.deepseek.com`
   - `API Key`：填你在 2.3 申请的 Key
   - `提供商（provider）`：选 OpenAI 兼容（DeepSeek 默认兼容 OpenAI 协议）
3. 之后用法和 Trae 一样：**选中代码提问、`@` 引用文件、对话改代码**。

> 💡 插件界面各家略有不同，但核心就三样：`base_url`、`model`、`api_key`。填对这三样，任何"OpenAI 兼容"接口都能接进去。

### 方式 C：零配置（还没 Key 之前先用）

没拿到 API Key 之前，可以**开两个窗口**先练着：

- 左边：VS Code 写代码
- 右边：网页版 DeepSeek，把"报错信息 + 相关几行代码"贴进去问

等熟悉了，再升级到方式 A / B。

## 2.3 Skill（技能）：让 AI 具备"专业工种"能力 💡

> 前面是"问一句、答一句"。**Skill** 是更高阶的玩法：它把"特定任务怎么做"打包成一个可复用的**技能/能力包**，让 AI 不只是聊天，而是能真的**产出文件**——PPT、文档、表格、图表、图，都不是空口建议，而是能打开的真文件。

**Skill 是什么（大白话）**
普通对话时，你说"帮我做个 PPT"，AI 只能给你文字大纲；但**启用了对应 Skill 后**，AI 能当场生成一个可打开的演示文稿文件。相当于给 AI 装了"职业模块"：

- 文档类：帮你写/排版一份实验报告、结课作业
- 表格类：帮你解析 ×lsx，做统计和图表
- 演示类：生成 PPT / 幻灯片
- 图表类：生成流程图、概念图、数据可视化
- 文档处理类：把 PDF / Word 转成你要的格式

**在哪里找、怎么用（以 Trae 为例）**
1. 在主界面找**技能中心 / 技能市场**（通常在侧边栏），浏览已安装或可添加的技能，每个都有说明和示例。
2. 对话时，在输入框敲 `/` 会呼出技能列表，选择你想用的那个再描述需求。
3. 直接描述需求也可能自动触发匹配的技能，比如："帮我把这几行成绩做成一个柱状图"。

**四个新手小例子（试一试）**
- "生成一份《我的特长介绍》的 PPT，3 页"
- "把这份课程表整理成表格"
- "画一张'冒泡排序'的流程图"
- "把这段实验记录写成一份规范的实验报告"

**小提醒**
- Skill 也是 AI 生成的，**结果要自己检查**、再按自己的想法改。
- 一个技能一般只擅长一类任务，先看它的说明，别让它做不擅长的事。
- 学会看"这个需求该用哪个技能"，和学会问问题一样重要。

> 一句话区分本章几个概念：**2.1 网页对话** 是"问AI"；**2.2 编辑器内用 AI** 是"在写代码的地方用 AI"；**2.3 Skill** 是"让 AI 用打包好的专业能力产出文件"；**2.4 API** 是"用代码把 AI 接进自己的程序"。

## 2.4 API：把大模型接进你自己的程序

上面方式是"人在编辑器里用 AI"。这一节教你**用代码直接调 DeepSeek**——这是把 AI 变成你程序一部分的关键。（同样用 DeepSeek 演示，OpenAI 兼容接口，一通百通。）

1. **拿 Key**：到 [platform.deepseek.com](https://platform.deepseek.com/) 注册登录 → 「API Keys」→ 创建新 Key → 复制保存（**只显示一次**，别弄丢）。
2. **保护 Key**（别写死在代码里，重要！）：
   - 项目里建 `.env` 文件：
     ```
     DEEPSEEK_API_KEY=你的Key
     ```
   - 建 `.gitignore` 文件，加一行 `.env`，防止把 Key 提交到 GitHub 泄露。
3. **装库**：
   ```bash
   pip install openai python-dotenv
   ```
   > DeepSeek 用的是 OpenAI 兼容接口，所以可以直接用 `openai` 这个官方库，只改地址。
4. **写调用**（新建 `llm_test.py`）：
   ```python
   import os
   from dotenv import load_dotenv
   from openai import OpenAI

   load_dotenv()                       # 读取 .env 里的 Key
   client = OpenAI(
       api_key=os.getenv("DEEPSEEK_API_KEY"),
       base_url="https://api.deepseek.com",   # ★ 这是关键：换成 DeepSeek 的地址
   )
   resp = client.chat.completions.create(
       model="deepseek-chat",          # 或 deepseek-reasoner（推理版）
       messages=[
           {"role": "system", "content": "你是一名耐心的大一助教"},
           {"role": "user", "content": "用三句话解释什么是边缘检测"},
       ],
   )
   print(resp.choices[0].message.content)
   ```
5. **运行**：`python llm_test.py`，能打印出回答即成功。
6. **进阶（结合你的方向）**：把第 1 章你的 C 代码、或后面第 9 章 OpenCV 识别的结果拼进 `content`，让模型帮你总结、决策——这就是"AI 小助手"的雏形。

> 换掉 `base_url` 和 `model` 就能接通义、Kimi、智谱等其他"OpenAI 兼容"的国内模型。关键就是抓住 `base_url` + `model` + `api_key` 这个万能三件套。

## 2.5 让 AI 更好用的小技巧

- **给它一个角色**（系统提示词）："你是一名循序渐进的大一编程教练，先给思路，再给代码"——回答质量会明显变好。
- **要"最小可运行例子"**：让它给能直接跑的完整代码，而不是片段。
- **报错贴全**：把**完整报错信息 + 相关几行代码**一起贴，比只贴"报错了"有用 10 倍。
- **先看懂再用**：AI 也会错。让它解释你为什么，而不要盲目复制。
