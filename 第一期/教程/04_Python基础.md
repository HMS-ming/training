# 4. 🟢 Python 基础 🐍

> ✨ [← 返回教程索引](../第一期教程.md)

**目标：** 配置环境，跑通 Python，为机器学习/图像处理打底。
**预计：** 1~2 周。学完 C 再来会觉得很容易。

---

1. 安装 VS Code，装 Python 插件。
2. 认识 Miniconda 和虚拟环境（详见 [`learningMd/MinicondaUse.md`](../learningMd/MinicondaUse.md)）。
3. 写第一个程序：
   ```python
   print("Hello, LightChaser!")
   ```
4. 运行验证。
5. 试着对比一下和第 1 章 C 的写法，体会"Python 更省事"：
   ```python
   # 第 1 章 C 里要 scanf + printf 半天，Python 一行
   name = input("你的名字：")
   print(f"你好，{name}！")
   ```
