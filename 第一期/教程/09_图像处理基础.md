# 9. 🟢 图像处理基础 📹️

> ✨ [← 返回教程索引](../第一期教程.md)

**目标：** 用 OpenCV 完成图片的读取、显示、保存。
**前置：** 完成第 4 章（Python 基础）。
**预计：** 1 周。

---

1. 认识 OpenCV（环境见 [`learningMd/cv_conda.md`](../learningMd/cv_conda.md)）。
2. 写代码：
   ```python
   import cv2

   img = cv2.imread("example.jpg")        # 读入一张图片
   cv2.imshow("Image", img)               # 显示
   cv2.waitKey(0)
   cv2.destroyAllWindows()
   cv2.imwrite("output.jpg", img)         # 保存
   ```
3. 换一张你自己的照片，跑通，然后试着裁剪或转灰度（`cv2.cvtColor`）。
