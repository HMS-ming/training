## 1.0 先认识你要用到的东西

写 C 语言只需要两样东西：

1. **编译器 gcc**：把 C 代码翻译成电脑能运行的机器码。
2. **编辑器**：写代码的地方（我们推荐 VS Code）。

> 关于编译，新手最容易搞混的一句话：**你写的是 `.c` 的文本，电脑不认识；`gcc` 把它变成 `.exe`/可执行文件，电脑才能跑。**

## 1.1 装好环境（二选一）

- **用 Windows（最省事）**
  1. 到 VS Code 官网下载安装 [VS Code](https://code.visualstudio.com/)。
  2. 在 VS Code 左侧「扩展」里搜索并安装官方 **C/C++** 扩展（微软出品）。
  3. 安装编译器 MinGW-w64（内含 `gcc`），装完在终端输入 `gcc --version`，能看到版本号即成功。
- **在 Linux 上装（第 5 章会细讲，这里先跑通）**
  在终端执行：
  ```bash
  sudo apt update && sudo apt install -y gcc build-essential
  gcc --version   # 出现版本号即成功
  ```

## 1.2 你的第 1 个程序：Hello World

新建一个文件夹 `01_C语言基础`，在里面建文件 `hello.c`，抄入下面全部内容：

```c
#include <stdio.h>      // 引入"标准输入输出"库，才能用 printf

int main() {            // 程序从这里开始执行
    printf("Hello, LightChaser!\n");   // 打印一行文字；\n 是换行
    return 0;           // 告诉系统"正常结束"
}
```

**怎么运行：** 在 `01_C语言基础` 目录打开终端，输入：

```bash
gcc hello.c -o hello   # 第 1 次：把 hello.c 编译成可执行文件 hello
./hello                # 第 2 次：运行它（Windows 下是 hello.exe）
```

**应该看到：** `Hello, LightChaser!`
**如果报错：**
- 提示"找不到 gcc" → 环境没装好，返回 1.1 检查。
- 提示第几行有语法错误 → 多半是丢了分号 `;` 或引号，逐字对比上面代码。

> Windows 编译的小坑：终端里运行是 `hello.exe`；如果报"无法将'./hello'识别为命令"，就用 `.\hello.exe`。

## 1.3 变量和数据类型

程序要存数据，得先"申请"一个盒子并告诉它装什么：

```c
#include <stdio.h>

int main() {
    int age = 18;            // 整数
    float score = 92.5;      // 小数
    char level = 'A';        // 单个字符（注意单引号）
    printf("年龄 %d 岁，成绩 %.1f 分，等级 %c\n", age, score, level);
    return 0;
}
```

- `%d` 打印整数、`%f` 打印小数、`%c` 打印字符——这叫**格式占位符**。
- 最常用的类型：`int`（整数）、`float`/`double`（小数）、`char`（字符）。

动手：改一改 `age` 的值，再运行，看输出变化。

## 1.4 输入：让程序读取你敲的内容（scanf）

```c
#include <stdio.h>

int main() {
    int n;
    printf("请输入一个整数：");
    scanf("%d", &n);        // & 记住——scanf 里变量前面要加 &（取地址）
    printf("你输入的是：%d\n", n);
    return 0;
}
```

> 新手经常忘 `&` 或忘 `;`，报错时先查这两处。

## 1.5 分支和循环

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; i++) {      // 循环 5 次，i 从 1 到 5
        if (i % 2 == 0)                 // 判断：i 是否能被 2 整除
            printf("%d 是偶数\n", i);
        else
            printf("%d 是奇数\n", i);
    }
    return 0;
}
```

练习思路：把 `i <= 5` 改成 `i <= 100`，就是打印 1~100 的奇偶。

## 1.6 函数：把一段逻辑包装起来

```c
#include <stdio.h>

int square(int x) {        // 定义函数：输入 int x，返回它的平方
    return x * x;
}

int main() {
    int n;
    printf("请输入一个整数：");
    if (scanf("%d", &n) != 1) return 1;   // 没读到正确的数就退出
    printf("%d 的平方是 %d\n", n, square(n));
    return 0;
}
```

> 函数三要素记牢：**返回类型 + 函数名 + 参数**。`int square(int x){ ... }` 就符合。

## 1.7 数组：装一列数据

```c
#include <stdio.h>

int main() {
    int a[5] = {10, 20, 30, 40, 50};   // 一个能装 5 个 int 的数组
    for (int i = 0; i < 5; i++) {
        printf("a[%d] = %d\n", i, a[i]);
    }
    return 0;
}
```

> **下标从 0 开始**！`a[i]` 里的 i 从 0 数到 4，没有 a[5]——这就是后面要讲的"越界"。

## 1.8 ★ 重点：指针与内存（本章最高手，多读几遍）

先看一个生活类比：**内存 = 一排编了号的柜子；变量 = 一个柜子；指针 = 一张写着"柜门编号"的小纸条。**
拿到"编号（地址）"，就能通过纸条找到并改动那个柜子。

```c
#include <stdio.h>

int main() {
    int a = 42;               // 数字 42 躺在某个柜子里
    printf("a 的值 = %d\n", a);
    printf("a 的地址 = %p\n", (void*)&a);   // &a 就是"a 所在柜子的编号"

    int *p = &a;              // 纸条 p 上写着"a 的地址"
    printf("p 里存的是 a 的地址：%p\n", (void*)p);
    printf("*p 就是通过纸条找到的值：%d\n", *p);  // *p = a = 42

    *p = 100;                 // 通过纸条改柜子里的内容
    printf("改完之后 a = %d\n", a);   // a 变成 100 了！
    return 0;
}
```

**关键一句话：**
- `&` 取地址，`*` 解引用（沿地址找值）。
- `int *p` 读作"p 是一个指向 int 的指针"。
- **数组名本身就是指针**：`a[i]` 相当于 `*(a + i)`。

## 1.9 动态内存：malloc / free

有时候数组要几个格子一开始不知道，就等运行时再申请：

```c
#include <stdio.h>
#include <stdlib.h>     // 要用 malloc / free

int main() {
    int n;
    printf("要几个数？ ");
    if (scanf("%d", &n) != 1) return 1;

    int *arr = (int*)malloc(n * sizeof(int));   // 申请 n 个 int 的空间
    if (arr == NULL) {        // 申请失败要处理，不然下面会崩
        printf("内存不足\n");
        return 1;
    }

    for (int i = 0; i < n; i++) arr[i] = i * 10;
    for (int i = 0; i < n; i++) printf("arr[%d]=%d ", i, arr[i]);
    printf("\n");

    free(arr);        // ★ 用完后必须释放，不然内存泄漏
    arr = NULL;       // ★ 置空，防止变成野指针
    return 0;
}
```

## 1.10 内存安全三不要（考试和写代码都要注意）

- **别越界**：别去碰 `a[5]` 之类不存在的格子，会踩到别的柜子。
- **别用野指针**：别用还没赋值、或已经 `free` 的指针。
- **别泄漏**：`malloc` 了就要 `free`，一一对应。
