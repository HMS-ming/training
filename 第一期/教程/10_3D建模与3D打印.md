# 10. 🟢 3D 建模与 3D 打印 🧱
**🧭 方向：机械（结构 / 3D）**

> ✨ [← 返回教程索引](../第一期教程.md)

**目标：** 学会用一个建模软件把想法"画"成立体零件，并用 3D 打印机/切片软件把它真正做出来。
**前置：** 无（对编程基本无要求，适合对结构、手工感兴趣的同学）。
**预计：** 1~2 周。
**需要：** 一台装了建模软件（SolidWorks 或 FreeCAD）的电脑；打印机在实验室用团队的。

---

## 10.1 为什么机械方向要从 3D 建模开始

机器人/产品除了代码，还得有**能动的结构**——外壳、支架、关节件。而结构设计的第一步，就是把零件在软件里建出来（建模），再决定怎么造（3D 打印 / CNC / 加工）。

## 10.2 选一个建模软件

- **SolidWorks**：工业界最常用，功能全，团队项目大概率能用上（但付费，学校/实验室一般有授权）。
- **FreeCAD**：免费开源、跨平台，个人学零门槛，适合先上手。
- **Tinkercad**：网页版，只需拖拽，适合初次接触的 10 分钟体验。
- 👉 新手建议：**先 Tinkercad 玩 10 分钟**建立信心 → 认准 FreeCAD 或 SolidWorks 深入一个。

## 10.3 建模的最小流程（以 SolidWorks/FreeCAD 为例）

1. 新建零件 → 选一个**基准面**。
2. 在这个面上画**草图**（拉伸的轮廓，比如一个矩形或圆）。
3. **拉伸**（Extrude）：把草图"拉"成有厚度的立体。
4. 再加工：**切除**（挖洞）、**倒角**（修圆角）、**阵列**（复制多个）。
5. 反复加步骤，就能搭出一个立体的外壳/支架。

> 核心心法：**草图 → 拉伸 → 再加工**，几乎所有零件都是这套节奏。

## 10.4 把它打出来：切片 + 打印

模型存成 STL/OBJ 后，用**切片软件**（Cura / 打印机制附录）转成打印机读得懂的文件，再送打印机：

1. 导入 STL → 摆放、设层高（0.2mm 左右）/填充率（20% 足够）→ 生成 G-code。
2. 把 G-code 拷到打印机（SD 卡或直连）→ 开始打印。
3. 打完清理支撑 → 一个"想出来又做出来"的零件到手。

## 10.5 动手练习清单

- [ ] Tinkercad 或 FreeCAD 里做一个带圆角的"铭牌/钥匙扣"
- [ ] 用 SolidWorks/FreeCAD 画一个能套进螺母的六边形螺母
- [ ] 进阶：做一个**两个零件能拼起来**的装配（比如一盖一盒）
- [ ] （实验室条件允许）把我们做的挂件/铭牌**打出来**一个实物
- [ ] 把每个阶段的建模截图存档（这就是你的作品集）

## 10.6 本章验收（交付）

- 完成至少一个零件建模（截图）
- 有条件的打印出实物；没有打印机则提交建模文件（.SLDPRT / .FCStd / .STL）
- 把你的建模作品和截图提交到 Git
