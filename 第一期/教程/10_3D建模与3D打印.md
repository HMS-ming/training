# 10. 🟢 3D 建模与 3D 打印 🧱
**🧭 方向：机械（结构 / 3D）**

> ✨ [← 返回教程索引](../第一期教程.md)

**目标：** 学会用一个建模软件把想法"画"成立体零件，并用 3D 打印机/切片软件把它真正做出来。
**前置：** 无（对编程基本无要求，适合对结构、手工感兴趣的同学）。
**预计：** 1~2 周。
**需要：** 一台装了建模软件（推荐 **Fusion 360** 免费版）的电脑；打印机在实验室用团队的。

---

## 10.1 为什么机械方向要从 3D 建模开始

机器人/产品除了代码，还得有**能动的结构**——外壳、支架、关节件。而结构设计的第一步，就是把零件在软件里建出来（建模），再决定怎么造（3D 打印 / CNC / 加工）。

## 10.2 选一个建模软件（入门首选 Fusion 360）

- **Fusion 360**：Autodesk 出品，**个人 / 学生免费**，登录账号就能用，跨 Windows/Mac，从建模、渲染到切片一站式，非常适合 3D 打印入门。**推荐首选。**
- **FreeCAD**：免费开源、完全离线，Windows 也能装，适合不想注册账号的同学。
- **Tinkercad**：网页版、只要拖拖拽拽，适合第一次接触时"10 分钟体验"。
- 👉 新手建议：**先在 Tinkercad 玩 10 分钟**建立信心 → 认准 **Fusion 360** 深入一个。
- （注：工业界常用的 **SolidWorks** 也很有用，但那是**第 11 章机械设计**方向的主力软件；本章入门先用 Fusion 360 就好。）

## 10.3 建模的最小流程（以 Fusion 360 为例）

1. 新建一个**设计** → 选一个**基准面**。
2. 在这个面上画**草图**（拉伸的轮廓，比如一个矩形或圆）。
3. **拉伸**（Extrude）：把草图"拉"成有厚度的立体。
4. 再加工：**切除**（挖洞）、**圆角**（修圆边）、**阵列**（复制多个）。
5. 反复加步骤，就能搭出一个立体的外壳/支架。

> 核心心法：**草图 → 拉伸 → 再加工**，几乎所有零件都是这套节奏。

## 10.4 把它打出来：切片 + 打印

模型存成 STL/OBJ 后，用**切片软件**（Cura / 打印机制附录）转成打印机读得懂的文件，再送打印机：

1. 导入 STL → 摆放、设层高（0.2mm 左右）/填充率（20% 足够）→ 生成 G-code。
2. 把 G-code 拷到打印机（SD 卡或直连）→ 开始打印。
3. 打完清理支撑 → 一个"想出来又做出来"的零件到手。

## 10.5 常用"特征"命令速查（建模主力武器）

模型 = 一堆"特征"（feature）堆出来的。这七个是最高频的：

| 特征 | 干嘛用 | 举个机器人例子 |
|------|--------|----------------|
| 拉伸 Extrude | 把草图变立体 | 一块底板 |
| 切除 Cut | 挖洞 / 开槽 | 给螺丝挖沉孔 |
| 圆角 Fillet | 修圆边，强度好、好看 | 支架棱角 |
| 倒角 Chamfer | 切斜边，易装配 | 插拔件入口 |
| 阵列 Pattern | 复制一排 | 4 个安装孔 |
| 抽壳 Shell | 把实心变薄壳 | 外壳（很省材料） |
| 螺纹 Thread | 画螺纹 | 散热座螺口 |

> 先记住"**拉伸 + 切除 + 圆角 + 阵列**"就够做 50% 的零件了，其余用到再学。

## 10.6 装配与让件"能动起来"（机械的灵魂）

单个零件只是"死块"，**装配（Assembly）**才让它有结构意义：

1. 新建一个**装配体**，插入两三个零件。
2. 用**配合（Mate / Constraint）**约束它们：面贴合、孔对孔、轴重合。
3. 想验证运动（比如关节转动），就加"旋转配合/角度约束"试试动起来。
4. **爆炸图**：把装配体拆开摆开，直观展示"这玩意儿由哪些件组成"。

> 装配跟 ROS 很像：零件就像"节点"，配合就像"约束"，约束好了整个结构才"站得住、动得起来"。

## 10.7 打印参数真的会灵（小项目：做一个"双卡卡片扣"）

把 10.4 的参数落到一个具体小件上——**做一个能插进两张卡片的卡扣**：

1. 草图：画一块约 `90 × 55 × 3 mm` 的板子，拉伸。
2. 在背面挖三个槽：两槽插卡片（槽宽约 1.2mm），一槽是安装孔。
3. 出成 STL，用切片软件：**层高 0.2mm、填充率 20%**、加支撑（有悬空面就开）。
4. 打印 → 试试插卡片顺不顺，不顺就微调槽宽再打。

> 做这种"要插要卡"的东西，你会真正体会**公差的感觉**：留 0.1~0.3mm 间隙才插得进。这正好接上了第 11 章的"公差与配合"。

## 10.8 动手练习清单

- [ ] 在 Tinkercad 或 Fusion 360 里做一个带圆角的"铭牌/钥匙扣"
- [ ] 用 Fusion 360 画一个能套进螺母的六边形螺母
- [ ] 做一个**两个零件能拼起来**的装配（比如一盖一盒）
- [ ] 把外壳用"抽壳"做成薄壳，看看省多少材料（对比体积）
- [ ] 用"阵列"一次开 4 个安装孔
- [ ] （实验室条件允许）把我们做的挂件/铭牌**打出来**一个实物
- [ ] 把每个阶段的建模截图存档（这就是你的作品集）

## 10.9 本章验收（交付）

- 完成至少一个零件建模 + 一个简单装配体（截图）
- 掌握"拉伸 / 切除 / 圆角 / 阵列"四个特征
- 有条件的打印出实物；没有打印机则提交建模文件（.f3d / .step / .stl）
- 把你的建模作品和截图提交到 Git
