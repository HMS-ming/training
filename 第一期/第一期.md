## 🎯 本次培训重点（重要，先读这一节）

**前三章是本学期培训的核心，必须认真完成并交付成果：**

1. **C/C++ 语言基础** —— 编程地基，后面嵌入式 / 机器人全靠它
2. **大模型基础** —— 会用 AI 提效，会用 API 接进自己的程序
3. **Git 基础** —— 版本管理，学会"存历史、可回退、提交作业"

前三章之后，进入**公共基础**（Linux / Python 会一点即可），然后**按兴趣挑一个方向**深入：

- 喜欢硬件、动手做板子 → **电控**（嵌入式 + ROS）
- 喜欢图像、AI、算法 → **算法**（图像处理 + 机器学习）
- 喜欢结构、3D、造东西 → **机械**（3D 建模 + 机械设计）

> 交付方式：前三章的练习完成后，提交到**自己的 Git 仓库**，把链接发给学长 / 放进团队仓库即算完成。详见[验收清单](第一期教程.md)。

## 📖 给大一新生的学习建议

- **不要怕零基础**：所有人都从这里开始，遇到不懂就问学长、问 AI。
- **先跑通，再搞懂**：先把例子抄着跑通，有成就感了再去问"为什么"。
- **动手 > 看完**：本手册全部是动手练习，光看不动是学不会的。
- **每次练完都提交 Git**：养成记录的习惯，期末就是你的成长档案。
- **卡住了怎么办**：① 对照示例逐字检查 → ② 把报错贴给 AI → ③ 问学长 → ④ 群里求助。
