## 📌 第一期 · 面向大一，零基础可入

从零开始，手把手入门 **嵌入式 / 视觉 / 电子信息**。共 **11 章**，分三个板块：

- 🔴 **核心必学**（本次培训重点，需交付成果）：`1 C/C++` → `2 大模型` → `3 Git`
- 🌐 **公共基础**（建议都会）：`4 Linux` → `5 Python`
- ⚡ **进阶方向**（挑一个深入）：
  - 🧿 **电控**：`6 嵌入式` + `7 ROS`
  - 🧠 **算法**：`8 图像处理` + `9 机器学习`
  - 🛠️ **机械**：`10 3D 建模与3D打印` + `11 机械设计基础`

> ✅ 学习主线：前三章吃透并交付 → 公共基础过一遍 → 挑一个方向做扎实。每章都配有 **B 站高播放推荐视频**。

## 📅 第一期培训时间安排

| 阶段 | 时间 | 内容 | 说明 |
|------|------|------|------|
| **核心必学** 🔴 | 9 月中 ~ **10.26** | 板块 0：1 C/C++ → 2 大模型 → 3 Git | **全体新人必学**，学完交付成果 |
| **最终面试** 🎯 | 10.26 起 | 验收核心成果 + 简单问答 | 面试通过 → 进入下一阶段 |
| **正式阶段 · 公共打底** 🌐 | 面试通过后约 2~3 周 | 4 Linux → 5 Python | 正式成员补齐公共基础 |
| **正式阶段 · 方向分流** ⚡ | 公共打底后 | 电控 STM32 / 算法 视觉+ML / 机械 SW | 按兴趣 + 面试表现定岗 |

> 核心必学是**全员门槛**，过 10.26 面试后才进入正式阶段；后续按 **Linux+Python 公共打底 → 按方向分流** 推进，方便全队统一公共能力、后面二次分工。

## 🤝 验收约定

- 核心 1~3 章做完需交付；进阶按你选的方向**挑一章做扎实**即可。
- 每章末尾有 🎯 **验收清单**，并附 B 站视频推荐；成果提交到你自己的 Git 仓库，**统一按 [`提交格式说明`](第一期/提交格式说明.md) 摆文件、写提交、发链接**，即算完成。
- 本手册每次改动前都会做**带时间戳的版本备份**，并更新 [`CHANGELOG.txt`](CHANGELOG.txt) 说明，方便回退。
